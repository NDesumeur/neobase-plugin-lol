# Invocateur (League of Legends)

Plugin NeoBase : lie ton compte Riot (Riot ID + région + clé d'API) et retrouve tes dernières parties, tes statistiques (KDA, sbires/min, vision, dégâts, taux de victoire), tes champions, tes maîtrises, ton classement et des courbes d'évolution.

- Les données viennent de l'API officielle de Riot et de Data Dragon (images). Une clé de développement (developer.riotgames.com) dure 24 h : remplace-la d'un clic.
- Aucun mot de passe n'est demandé. La clé reste dans le dossier du plugin sur ton PC.
- Les parties déjà chargées sont gardées : les courbes continuent au-delà des 20 dernières parties.

NeoBase ne l'ouvre que si elle est signée.
